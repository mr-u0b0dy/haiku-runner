haiku-runner Documentation

Zephyr-based multi-input speaker for the nRF5340 DK: LE Audio, USB Audio Class and analog AUX inputs feeding a shared pipeline out to an I2S amplifier.

USB audio is verified working end to end. LE Audio is complete on the device side but has never streamed for want of a capable source, and AUX needs an external analog front-end. [Project Status](/status) has the full picture.
